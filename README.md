# Dynamic Pricing Engine

This project is a Python-based dynamic pricing and forecasting system.

## Features
- Calculates pricing recommendations based on demand and wastage
- Generates demand forecasts using historical averages
- Stores data in SQLite database
- Sends results to Airtable dashboard

## Project Structure
dynamic-pricing-engine/
│── data/
│── database/
│── outputs/
│── scripts/
│── screenshots/

## How to Run

Run pricing engine:
python scripts/run_pricing_engine.py

Run forecast:
python scripts/run_forecast.py

Send to Airtable:
python scripts/run_pricing_to_airtable.py

## Tech Used
- Python
- Pandas
- SQLite
- Airtable API
